# Handoff HERMES-OC-01

Copiar este bloque a la sesión del repositorio destino. No incluir secretos ni datos personales.

- ID de tarea: `<id>`
- Fecha y zona horaria: `<fecha>`
- Origen: `<repositorio, rama, HEAD, worktree>`
- Destino: `<repositorio>`
- Solicitud y alcance: `<resumen>`
- Contrato o archivos relevantes: `<rutas y versiones>`
- Evidencia verificable: `<commit, PR o archivo con fecha y rama>`
- Resultado del análisis: `<hallazgos>`
- Riesgos y dependencias: `<detalle>`
- Validaciones ejecutadas: `<comando y resultado, o NOT_RUN>`
- Validaciones pendientes: `<detalle>`
- Decisión humana requerida: `<aprobación concreta>`
